Line Balancing Game: Balance the Line (Throughput vs Labor Cost)

Goal: Assign tasks to stations. The slowest station determines the line’s cycle time. More stations cost more.

1) Configure the scenario

How it works
Cycle time = max station time. Units produced ≈ floor(runtime / cycle time).
If you add stations but don’t reduce the slowest station time, output won’t improve.

2) Tasks (editable)

You can change task times (seconds). Keep it simple (4–8 tasks).
Precedence is assumed to be in listed order (Task 1 → Task 2 → …). Students balance by grouping tasks into stations.

3) Assign tasks to stations

For each station, choose which tasks it performs (in order). Add/remove stations as needed.

Results

Run a simulation to see throughput, bottleneck, and profit.
